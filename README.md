# 🌤️ AETHER – Weather Dashboard

AETHER is a modern, responsive weather application that provides real-time weather information, hourly forecasts, and 5-day weather forecasts using the Open-Meteo API.

## 🚀 Live Demo

https://zunaedafif10.github.io/Aether/

## ✨ Features
- Search weather by city
- Real-time temperature and weather conditions
- Hourly and 5-day forecasts
- Humidity, wind speed, and pressure
- Sunrise and sunset times
- Save favorite cities using Local Storage
- Responsive dark UI

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Local Storage

## 📂 Installation

1. Clone the repository:
   `git clone https://github.com/ZunaedAfif10/Aether.git`
2. Open the project folder.
3. Run `index.html` using Live Server.
